## 📜 活动背景

> *「天机万象，皆有定数。然修道之人，以心测天，借星魂之力，可窥得造化之玄妙。」*

亿万年前，一位大能在陨落前将毕生修为凝练成五道战魂，封印于万象天机塔中。如今封印渐解，天机重启，唯有通过层层试炼的修士，方能获得这些上古战魂的认可，借其之力登临巅峰！

## 🎮 玩法介绍

**万象天机** 是一款 **Roguelike 爬塔玩法**，每次试炼都是一场独特的冒险！

### 📊 试炼流程

```
开启试炼 → 选择路线 → 战斗/奇遇/修整 → 收集赐福 → 挑战首领 → 结算奖励
     ↑                                                    |
     └────────────── 失败后重新开始 ←─────────────────────┘
```

### ⚔️ 核心玩法

| 要素 | 说明 |
|:----:|------|
| 🌟 **星魂** | 装备五行战魂出战，金·木·水·火·土各有所长 |
| 📜 **赐福** | 每场战斗后可选择增益效果，层层叠加 |
| 🏆 **天机印** | 试炼中获取的货币，可在云游散修处购买赐福 |
| 💎 **天机玉** | 通关结算奖励，可在天机阁兑换珍稀道具 |
| 📿 **誓约** | 自加难度获取更高收益，高手挑战专属 |

## 🗺️ 试炼层级

试炼共 **20层**，每5层迎来一位首领：

| 阶段 | 层数 | 内容 | 首领 |
|:----:|:----:|------|:----:|
| **初入试炼** | 1-5 | 石傀儡、藤蔓精、深寒怨灵 | 炽火妖莲 |
| **元素试炼** | 6-10 | 雷灵鸟、暗影刺客、狂暴猿猴 | 吞天巨蟒 |
| **机制高压** | 11-15 | 铁甲巨龟、锐金剑侍组合战 | 混元石魔 |
| **无尽深渊** | 16-20 | 旧首领沦为精英、四大金刚 | 混沌魔眼 |

> 💡 通关20层后解锁 **无限试炼模式**，挑战更高层数！

## 🎁 节点类型

## ⚠️ 注意事项

1. 🔄 试炼失败后需等待 **3分钟** 冷却
2. ⚔️ 星魂阵亡后当局无法复活 (除非遇到修整节点或特殊奇遇)
3. 💎 退出试炼不会获得任何奖励
4. 📿 誓约需 **通关20层后** 才能选择
5. 🌟 建议先装备好星魂再开启试炼

## 📅 每日任务系统 (NEW)

全新上线的每日活跃系统，助道友仙途更进一步！
> 指令：`#每日任务`

### 任务详情

| 任务类型   | 目标         | 奖励积分 | 每日上限 |
|:-------|:-----------|:----:|:----:|
| **签到** | 每日签到1次     | +10  |  1次  |
| **秘境** | 探索10次/沉迷1次 | +20  |  1次  |
| **切磋** | 与人切磋1次     | +15  |  1次  |
| **经商** | 累计获得20w灵石  | +20  |  5次  |

*(每获得20w灵石计1次，最高可得100分)*

### 积分奖励

积分自动累积，达到标准后**自动发放**到背包：

- **25分**：灵石×20,000
- **60分**：灵石×100,000
- **95分**：血气瓶×20
- **150分**：七星玄元丹×1

## ⚔️ 天地榜 2.0 重制

### 核心升级

- **六大段位**：凡俗 ➔ 练气 ➔ 筑基 ➔ 金丹 ➔ 元婴 ➔ 化神。
- **赛季结算**：每周为一个赛季（周日休战结算），前50名可获得【天地令】与专属称号。
- **连胜机制**：
    - 3连胜：积分×1.2
    - 7连胜：积分×2.0 + 连胜宝匣
    - 10连胜：**全服公告** + 称号「天榜连胜王」

### 🎁 连胜宝匣

7连胜获得的宝匣可通过 `#打开连胜宝匣` 开启，随机获得以下奖励之一：

| 奖励 | 概率 |
|:---|:---:|
| 灵石×2w | 60% |
| 摘榜令×1 | 15% |
| 荣耀点×5 | 10% |
| 摘榜令×2 | 5% |
| 荣耀点×20 | 5% |
| 七星玄元丹×1 | 2.5% |
| 天地令×50 | 2.5% |

### 🌌 天象系统

天地灵气异动，每3-7天随机轮转天象，影响五行生克：

- **灵气潮汐**：法术伤害+60%，物理伤害-40%
- **杀劫降临**：全员伤害翻倍，血量上限-30%
- **五行失衡**：特定灵根属性大幅增强或削弱

> 指令：`#当前天象`

### 🏛️ 天地堂 (赛季商店)

使用**荣耀点**与**天地令**兑换珍稀道具：

#### 🪙 货币获取
| 货币 | 获取方式 | 说明 |
|:---:|:---|:---|
| **荣耀点** | 天地榜比试 | 每次比试积分的 **1/30** 转化为荣耀点 |
| **天地令** | 赛季结算 | 赛季结束时，前 **50名** 可获得 10-50 枚 |

#### 🎁 兑换列表

- **五行调和丹**：免疫天象负面效果
- **连胜守护符**：保级必备，失败不中断连胜
- **专属称号**：「天地弄潮儿」

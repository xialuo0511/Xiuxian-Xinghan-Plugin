### 🔥 核心升级

#### 存储架构迁移

彻底重构数据存储层，从 JSON 文件迁移至 **Redis** 数据库：

| 改进 | 说明 |
|------|------|
| ✅ 高性能存储 | Redis 取代 JSON 文件，大幅提升读写效率 |
| ✅ 分布式锁 | 防止并发写入冲突，确保数据一致性 |
| ✅ 异步任务调度 | 后台独立进程处理定时任务 |
| ✅ 事务安全 | WATCH + MULTI/EXEC 双重保障 |

#### 系统架构

```

│  │  指令处理层  │──▶│   逻辑层    │──▶│    数据模型层     │  │
```

### 📦 数据迁移

从旧版本升级需要执行数据迁移：

1. **备份旧数据**
2. **停止机器人**（保持 Redis 运行）
3. **执行迁移脚本**：`node migrate-to-redis.js`
4. **重启机器人**

详见 [安装教程 - 数据迁移](/guide/install#数据迁移)

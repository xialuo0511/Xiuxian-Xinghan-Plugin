# 寻宝系统 (Treasure Hunt)

寻宝系统是修仙模拟器中获取资源的重要途径之一，分为**普通寻宝**和**寻宝祈愿**两种主要玩法。

## 一、 普通寻宝

通过使用特定的“地图”道具，玩家可以前往对应地点进行寻宝，获取丰厚的资源奖励。

**指令**：`#寻宝 [地图名]`
**示例**：`#寻宝 天衡山`

### 寻宝机制
- **前置要求**：背包中必须拥有对应的地图道具。
- **消耗**：每次寻宝消耗1张地图。
- **耗时**：寻宝需要一定的时间（通常为几分钟），期间玩家处于“寻宝中”状态。
- **奖励**：每次寻宝会从该地图的“最佳奖励列表”中**等概率随机**获得一种奖励。

### 地图与奖励一览表

| 地图名称 | 可能获得的奖励 (随机一种) | 概率 |
| :--- | :--- | :--- |
| **天衡山** | 煤炭、铁矿、魔山地图 | 各 33.3% |
| **天臂池** | 经验瓶、经验球、血气瓶 | 各 33.3% |
| **星落湖** | 钓鱼掉上来的奇怪盒子 | 100% |
| **低语森林** | 水天丛林地图、泥土、树苗、苹果 | 各 25% |
| **水天丛林** | 深渊地图、泥土、树苗、西瓜 | 各 25% |
| **恒那兰那** | 铁矿、煤炭、轻策庄、书架 | 各 25% |
| **轻策庄** | 书架、书本、黑曜石、深渊、甘蔗 | 各 20% |
| **降诸魔山** | 星荧洞窟地图、腐肉、骨头 | 各 33.3% |
| **星荧洞窟** | 层岩洞窟地图、腐肉、骨头、红石 | 各 25% |
| **层岩洞窟** | 深渊地图、腐肉、骨头、红石 | 各 25% |
| **深渊** | 七星海棠丹、岩浆 | 各 50% |

> **提示**：除了上述物品外，每次寻宝还有可能获得**灵石**奖励（5万~20万不等）。

## 二、 寻宝祈愿 (抽奖)

寻宝祈愿是另一种通过消耗特定材料来抽取珍稀道具的玩法。

### 1. 寻宝常驻祈愿
消耗“泥土”进行抽奖，主要产出基础材料和部分稀有附魔草药。

- **单抽指令**：`#单抽寻宝常驻祈愿`
- **十连指令**：`#十连抽寻宝常驻祈愿`
- **消耗**：泥土
- **核心奖励**：
    - **稀有草药**：雷鸣阎狱藤, 烈火杏娇疏, 绮罗郁金香, 八角玄冰草, 蓝银皇, 地瓜岩龙, 万妖王
    - **普通材料**：番琉璃, 角石, 熟肉, 苹果, 西瓜, 胡萝卜, 土豆, 小麦, 面包, 腐肉, 鱼肉, 烤鱼

### 2. 寻宝活动祈愿
消耗“树苗”进行抽奖，有机会获得极其珍贵的限定道具。

- **单抽指令**：`#单抽寻宝活动祈愿`
- **十连指令**：`#十连抽寻宝活动祈愿`
- **消耗**：树苗
- **核心奖励**：
    - **超稀有**：[无主的神之心] (集齐七颗可召唤天理)
    - **稀有**：附魔台, 岩浆, 深渊石, 百合花篮
    - **普通**：甘蔗, 寻物纸

### 3. 附魔台 (附魔书祈愿)
消耗“青金石”和“书本”抽取附魔书，用于强化装备。

- **单抽指令**：`#单抽附魔台`
- **十连指令**：`#十连抽附魔台`
- **消耗**：青金石 × 1 + 书本 × 1 (单次)
- **机制**：
    - 如果玩家拥有的“书架”数量小于50，则奖池会进行轮换。
    - 否则从所有常驻附魔书中随机抽取。

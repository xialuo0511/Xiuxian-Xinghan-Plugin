# 战斗系统

星瀚修仙提供丰富多样的战斗玩法，包括 PVP 切磋、PVE 秘境探索、塔楼挑战等。

## PVP 战斗

### 以武会友

无限制的友好切磋，不消耗资源，无伤亡：

```
@群友 以武会友
```

::: tip 特点
- 无次数限制
- 无奖励惩罚
- 纯粹的实力对比
:::

### 比武

正式的战斗模式，有血量要求和奖励：

```
@群友 比武
```

- 需要满血状态
- 胜者获得气血和灵石奖励
- 败者损失少量灵石

### 打劫

风险与收益并存的战斗方式：

```
@群友 打劫
```

- 胜者获得败方部分灵石
- 存在失败风险

### 残云封天剑

特殊的禁言攻击（需要群管理权限）：

```
@群友 残云封天剑
```

对方将被禁言，使用 `除你禁言` 可解除。

## PVE 战斗

### 秘境探索

探索各种秘境获取装备和材料：

| 指令 | 说明 |
|------|------|
| `#探寻遗迹xxx` | 前往探索遗迹 |
| `#遗迹` | 查看遗迹列表 |

秘境中可能遇到：
- 普通怪物 - 掉落基础材料
- 精英怪物 - 掉落稀有装备
- BOSS - 掉落极品装备

### 镇妖塔

挑战塔层获取灵石：

```
#挑战镇妖塔
```

- 层数越高难度越大
- 通关后获得大量灵石奖励
- 挑战失败不损失进度

### 炼神魄

试炼自己获取血气：

```
#炼神魄
```

## 世界 BOSS

定期刷新的全服 BOSS 挑战：

| 指令 | 说明 |
|------|------|
| `#挑战世界BOSS` | 参与全服 BOSS 战 |

根据伤害排名获取奖励：
- 伤害越高，奖励越丰厚
- 击杀后全服分配奖励

## 战斗技巧

### 提升战力

1. **提升境界** - 境界是战力的基础
2. **装备强化** - 穿戴并强化优质装备
3. **学习功法** - 功法加成攻击防御
4. **培养仙宠** - 仙宠提供额外战力

### 战斗属性

| 属性 | 说明 |
|------|------|
| 攻击 | 影响伤害输出 |
| 防御 | 减少受到的伤害 |
| 血量 | 生存能力 |
| 暴击 | 暴击伤害概率 |

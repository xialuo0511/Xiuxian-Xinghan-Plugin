# 境界系统

星瀚修仙拥有完整的境界体系，包含**练气境界**和**炼体境界**两条并行的修炼路线。

## 练气境界

练气是修仙的核心路线，从凡人一路修炼至仙界巅峰。

## 炼体境界

炼体是与练气并行的修炼路线，注重**防御和血量**。

### 炼体阶段概览

| 大境界 | 小境界 | 特点 |
|--------|--------|------|
| 莽夫 | - | 炼体起点 |
| 炼皮 | 初期 → 圆满 | 锤炼皮肤 |
| 炼肉 | 初期 → 圆满 | 锤炼肌肉 |
| 炼筋 | 初期 → 圆满 | 锤炼筋脉 |
| 炼骨 | 初期 → 圆满 | 锤炼骨骼 |
| 炼血 | 初期 → 圆满 | 锤炼血液 |
| 炼脏 | 初期 → 圆满 | 锤炼脏腑 |
| 炼魂 | 初期 → 圆满 | 锤炼魂魄 |
| 炼神 | 初期 → 巅峰 | 锤炼神识 |
| 破体期 | - | 炼体渡劫 |

# 经济系统

灵石是星瀚修仙中的核心货币，贯穿所有玩法。本篇介绍游戏中的各种经济玩法。

## 灵石获取

### 日常获取

| 方式 | 说明 |
|------|------|
| `#修仙签到` | 每日签到获取灵石 |
| `#宗门俸禄` | 宗门成员每日领取 |
| `#开采灵脉` | 宗门灵脉采集 |

### 战斗获取

| 方式 | 说明 |
|------|------|
| `#挑战镇妖塔` | 通关获取大量灵石 |
| `@群友 打劫` | PVP 抢夺灵石 |
| 秘境探索 | 探索获取奖励 |

### 交易获取

| 方式 | 说明 |
|------|------|
| 出售物品 | 通过商店出售 |
| 拍卖行 | 玩家间交易 |

## 纳戒（背包）

纳戒是存放物品的容器：

| 指令 | 说明 |
|------|------|
| `#我的纳戒` | 查看背包物品 |
| `#打开钱包` | 查看灵石余额 |

## 商店系统

### 普通商店

```
#商店
#购买+物品名
```

### 遗迹商店

使用探索遗迹获取的代币兑换：

| 指令 | 说明 |
|------|------|
| `#遗迹商店` | 查看商店内容 |
| `#代币兑换xxx*数量` | 兑换商品 |

## 物品交易

### 出售物品

```
#出售+物品名
```

### 一键出售

快速出售指定类型的所有物品：

```
#一键出售+类型名
```

支持类型：装备、丹药、道具、功法、草药

### 赠送物品

```
#一键赠送+类型名
```

将物品赠送给其他玩家。

## 拍卖行

玩家间的自由交易市场：

| 指令 | 说明 |
|------|------|
| `#拍卖+物品+价格` | 上架拍卖物品 |
| 查看拍卖行 | 浏览在售物品 |
| 购买拍卖品 | 购买心仪物品 |

## 金银坊

高风险高回报的博弈玩法：

| 指令 | 说明 |
|------|------|
| `#金银坊` | 进入金银坊（需携带灵石） |
| `#金银坊记录` | 查看历史记录 |

::: warning 风险提示
金银坊存在输光灵石的风险，请量力而行！
:::

## 洗劫玩法

洗劫各大场所获取灵石：

```
#洗劫+地点名
```

支持地点：
- 柠檬堂
- 金银坊
- 万宝楼
- 星阁
- 万仙盟

洗劫前可以先探查：

```
#探查+地点名
```

## 经济建议

::: tip 新手经济攻略
1. **每日必做**：签到、宗门俸禄、开采灵脉
2. **稳定收入**：镇妖塔挑战是最稳定的灵石来源
3. **避免风险**：新手不建议进入金银坊
4. **加入宗门**：宗门福利是重要的灵石来源
:::

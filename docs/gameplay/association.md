# 宗门系统

宗门是星瀚修仙中最重要的社交系统之一。加入宗门可以获得丰富的日常福利，与门派兄弟姐妹共同成长。

## 加入宗门

### 查看宗门列表

```
#宗门列表
```

查看当前所有宗门及其信息。

### 加入宗门

```
#加入宗门xxx
```

申请加入指定宗门，部分宗门设有境界门槛。

### 退出宗门

```
#退出宗门
```

::: warning 注意
退出宗门后，贡献值将被清空！
:::

## 创建宗门

### 开宗立派

修为达到**化神境界**后可以创建自己的宗门：

```
#开宗立派
```

创建宗门需要消耗大量灵石。

## 宗门福利

### 每日俸禄

加入宗门后可以领取每日灵石：

```
#宗门俸禄
```

### 宗门贡献

通过捐赠灵石获取贡献值：

```
#宗门捐赠灵石xxx
```

贡献值可用于：
- 兑换宗门物品
- 提升宗门职位

### 查看贡献

| 指令 | 说明 |
|------|------|
| `#我的宗门` | 查看宗门信息 |
| `#我的贡献` | 查看个人贡献值 |
| `#宗门捐献记录` | 查看捐献历史 |

## 宗门管理

### 职位系统

宗门内有多个职位等级：
- **宗主** - 最高管理权限
- **副宗主** - 协助管理
- **长老** - 高级成员
- **内门弟子** - 核心成员
- **外门弟子** - 普通成员

### 任命职位

宗主和副宗主可以任命成员职位：

```
@群友 任命 内门弟子
```

### 逐出师门

```
#逐出师门@对方
#逐出+QQ号
```

宗主、副宗主和长老可以执行此操作。

### 宗门设置

```
#设置门槛+境界名
```

设置加入宗门的最低境界要求。

## 宗门建设

### 宗门升级

```
#宗门升级
```

消耗灵石提升宗门等级，提高：
- 灵石池上限
- 成员人数上限
- 解锁更多功能

### 护宗大阵

保护宗门的防御设施：

| 指令 | 说明 |
|------|------|
| `#查看护宗大阵` | 查看大阵血量 |
| `#维护护宗大阵xxx` | 消耗灵石维护 |
| `#宗门维护` | 保持7天正常运作 |

### 洞天福地

宗门可以入驻洞天福地获取加成：

```
#洞天福地列表
#入驻洞天xxx
```

## 宗门玩法

### 开采灵脉

```
#开采灵脉
```

为自己和宗门获取灵石。

### 宗门秘境

```
#宗门秘境
#探索宗门秘境+地点
```

探索宗门专属秘境获取奖励。

### 藏宝阁

宗门成员可以共享物品：

| 指令 | 说明 |
|------|------|
| `#宗门藏宝阁` | 查看藏宝阁 |
| `#放入xx*贡献值*数量*品级` | 存入物品 |
| `#收回xx*品级` | 取回物品 |
| `#兑换*数量*品级` | 用贡献兑换 |

### 宗门神兽

高级宗门可以召唤护山神兽：

| 指令 | 说明 |
|------|------|
| `#召唤神兽` | 召唤护山神兽 |
| `#神兽赐福` | 获取神兽祝福 |
| `#喂给神兽xxx` | 提升神兽好感 |

::: tip
神兽好感达到1000后会给予限定奖励！
:::

### 药园系统

宗门药园可以种植草药：

| 指令 | 说明 |
|------|------|
| `#药园` | 查看药园状态 |
| `#拔苗助长xxx` | 提前采收草药 |

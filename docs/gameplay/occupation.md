# 职业系统

星瀚修仙提供六大职业供玩家选择，每个职业都有独特的玩法和收益。

## 职业概览

| 职业 | 类型 | 主要收益 |
|------|------|----------|
| 🧪 炼丹师 | 生产 | 炼制丹药 |
| 🌿 采药师 | 采集 | 采集草药 |
| ⚒️ 炼器师 | 生产 | 打造装备 |
| ⛏️ 采矿师 | 采集 | 采集矿石 |
| ⚔️ 侠客 | 战斗 | 悬赏任务 |
| 🏹 猎户 | 采集 | 狩猎猎物 |

## 转职与切换

### 转职

```
#转职+职业名
```

例如：`#转职炼丹师`

### 副职系统

每个角色可以同时拥有**主职**和**副职**：

```
#转换副职
```

在主副职业之间自由切换。

### 查看等级

```
#职业等级
```

## 生产职业

### 炼丹师 🧪

专注于炼制各类丹药：

| 指令 | 说明 |
|------|------|
| `#丹药配方` | 查看可炼制丹药 |
| `#炼制+丹药名*N` | 炼制丹药 |

详见 [炼丹系统](/gameplay/alchemy)

### 炼器师 ⚒️

专注于打造各类装备：

| 指令 | 说明 |
|------|------|
| `#装备图纸` | 查看可打造装备 |
| `#打造+装备名` | 打造装备 |
| `#元素武器图鉴` | 查看神界武器 |

## 采集职业

### 采药师 🌿

采集各类草药供炼丹使用：

```
#采药N分钟
#结束采药
```

采药时间越长，收获越丰富。

### 采矿师 ⛏️

采集各类矿石供炼器使用：

```
#采矿N分钟
#结束采矿
```

### 猎户 🏹

狩猎野外猎物获取材料：

```
#狩猎N分钟
#结束狩猎
```

## 战斗职业

### 侠客 ⚔️

通过完成悬赏任务赚取灵石：

| 指令 | 说明 |
|------|------|
| `#悬赏目标` | 查看当前悬赏（每20h刷新） |
| `#讨伐目标+数字` | 讨伐指定目标 |
| `#刺杀目标+数字` | 刺杀目标（全员可参与） |

### 悬赏系统

任何玩家都可以发布悬赏：

| 指令 | 说明 |
|------|------|
| `#悬赏+qq号*金额` | 悬赏玩家 |
| `#赏金榜` | 查看悬赏榜单 |

## 职业收益对比

| 职业 | 优势 | 适合人群 |
|------|------|----------|
| 炼丹师 | 丹药自给自足 | 喜欢自己炼丹的玩家 |
| 采药师 | 草药材料充足 | 喜欢采集的玩家 |
| 炼器师 | 打造定制装备 | 追求极品装备的玩家 |
| 采矿师 | 矿石材料充足 | 供应炼器师的玩家 |
| 侠客 | 悬赏金收入高 | 喜欢战斗的玩家 |
| 猎户 | 猎物材料丰富 | 喜欢野外活动的玩家 |

::: tip 建议
- 主职选择**生产职业**（炼丹师/炼器师）
- 副职选择**采集职业**（采药师/采矿师）
- 这样可以实现材料和成品的自给自足！
:::

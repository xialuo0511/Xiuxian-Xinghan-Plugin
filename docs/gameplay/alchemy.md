# 炼丹系统

炼丹是星瀚修仙中的核心职业玩法之一。成为炼丹师后，你可以炼制各种丹药为自己和他人增强实力。

## 成为炼丹师

### 转职条件

发送 `#转职炼丹师` 即可转职为炼丹师。

::: tip 副职系统
每个角色可以拥有主职和副职，通过 `#转换副职` 可以在两个职业间切换。
:::

## 丹药类型

### 修为丹

提升修为的丹药：

| 丹药 | 效果 | 备注 |
|------|------|------|
| 培元丹 | +修为 | 基础丹药 |
| 聚灵丹 | +修为 | 中级丹药 |
| 七星玄元丹 | +大量修为 | 高级丹药 |

### 血气丹

恢复或提升血量的丹药：

| 丹药 | 效果 |
|------|------|
| 血气瓶 | 恢复血气 |
| 回春丹 | 恢复生命 |

## 炼丹流程

### 1. 获取配方

发送 `#丹药配方` 查看可炼制的丹药列表及所需材料。

### 2. 准备材料

通过以下方式获取炼丹材料：
- **采药**：`#采药N分钟` 在野外采集草药
- **秘境探索**：探索秘境获取稀有材料
- **商店购买**：部分基础材料可在商店购买

### 3. 开始炼制

```
#炼制+丹药名*数量
```

例如：`#炼制培元丹*10`

## 药效系统

服用丹药后会产生持续的药效：

| 指令 | 说明 |
|------|------|
| `#服用+丹药名` | 服用丹药 |
| `#一键服用修为丹` | 一键服用所有修为丹 |
| `#一键服用血气丹` | 一键服用所有血气丹 |
| `#我的药效` | 查看当前剩余药效 |

::: warning 注意
丹药存在服用上限，过量服用可能导致丹毒！
:::

## 职业等级

炼丹师有独立的职业等级系统：

| 指令 | 说明 |
|------|------|
| `#职业等级` | 查看当前职业等级 |

职业等级越高，可炼制的丹药品质越好，成功率也越高。

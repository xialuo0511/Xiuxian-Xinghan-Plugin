# 🎪 活动列表

本页面详细说明星瀚修仙的各类限时活动玩法。

## 🐎 天马牧场（新年活动）

### 活动时间
2026年春节期间

### 活动入口
发送 `#进入天马牧场` 进入秘境

### 玩法说明

#### 阶段一 · 驯马试炼
| 指令 | 说明 |
|------|------|
| `#捕捉天马` | 捕获野生天马 |
| `#驯服天马` | 驯服已捕获天马 |
| `#放生天马` | 放生可获灵石 |

驯服成功后可获得坐骑，增加移动速度。

#### 阶段二 · 魔驹讨伐
组队讨伐堕落神马，获取稀有奖励：
- 参与指令：`#参与讨伐`
- 需3人以上组队
- 每日限参与1次

#### 阶段三 · 灯谜祈福
| 指令 | 说明 |
|------|------|
| `#灯谜祈福` | 开始答题 |
| 答对3题 | 获得祈福礼盒 |
| 答对5题 | 额外获得限定称号 |

## 🌟 万象天机（长期活动）

### 活动入口
发送 `#开启试炼` 开始挑战

### 玩法说明
Roguelike爬塔玩法，组建星魂队伍挑战20层试炼。

#### 核心指令
| 指令 | 说明 |
|------|------|
| `#开启试炼` | 开始普通试炼 |
| `#开启无限试炼` | 解锁后可用 |
| `#挑战` | 挑战当前层 |
| `#选择路线X` | 选择路径 |
| `#选择赐福X` | 选择赐福 |
| `#试炼状态` | 查看状态 |
| `#天机阁` | 兑换商店 |
| `#天机榜` | 排行榜 |

#### 商店系统
- **天机印**：战斗获得，购买赐福
- **天机玉**：通关获得，永久强化

详细攻略请查看专题文档。

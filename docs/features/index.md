# 🆕 功能更新

本页面详细说明星瀚修仙的重大功能更新。

## ⚔️ 天地榜 2.0

::: tip 必须先报名
玩家需发送 `#报名天地榜` 才能参与本赛季挑战
:::

### 天象系统

每3-7天天象随机更替，影响所有对战：

| 天象             | 效果                    |
|----------------|-----------------------|
| 五行失衡·金/木/水/火/土 | 对应灵根攻击+50%，被克灵根-30%   |
| 变异灵潮           | 变异灵根(风/冰/雷/光/暗)攻击+40% |
| 体质共鸣           | 体质类防御+30%             |
| 魔气侵蚀           | 魔功类攻击+60%             |
| 轮回天劫           | 转生体攻击+50%             |
| 天道镇压           | 境界压制失效                |
| 杀劫降临           | 伤害+100%，血量-30%        |

### 五行克制

```
金 → 木 → 土 → 水 → 火 → 金
```

克制方伤害+20%，被克方-20%（变异灵根/体质/圣体不参与）

### 连胜机制

| 连胜   | 奖励                 |
|------|--------------------|
| 3连胜  | 积分×1.2             |
| 5连胜  | 积分×1.5 + 灵石×1.5    |
| 7连胜  | 积分×2 + 连胜宝匣        |
| 10连胜 | 积分×2.5 + 称号「天榜连胜王」 |

### 赛季制

> [!IMPORTANT]
> **每周结算**：周一~周六正常比试，周日为**结算日**（无法比试，可兑换物品）

赛季结算奖励：

| 排名     | 奖励                |
|--------|-------------------|
| 第1名    | 天地令×50 + 称号「天榜至尊」 |
| 2-3名   | 天地令×30 + 称号「榜上有名」 |
| 4-10名  | 天地令×20            |
| 11-50名 | 天地令×10            |

### 三货币体系

| 货币      | 获取方式   | 用途          |
|---------|--------|-------------|
| **积分**  | 比试获得   | 排名/段位/兑换消耗品 |
| **荣耀点** | 比试自动获得 | 消耗品快速兑换     |
| **天地令** | 赛季结算奖励 | 稀有限定物品      |

### 图片输出功能

- `#天地榜` 回复个人状态图片，包含：
    - 玩家信息、段位、排名、积分
    - 当前天象及剩余时间
    - 赛季结束倒计时
    - 结算日特殊标识

- `#比试` 回复战斗日志图片（与以武会友相同样式）

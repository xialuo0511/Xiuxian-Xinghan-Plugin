# 表情包生成系统需求文档

## 1. 概述

在修仙插件中集成一套类似 [PetPet Generator](https://petpetgenerator.net/) 的表情包生成系统，支持用户通过简单指令（如 `#摸头 @用户`）生成动态 GIF 表情包。

## 2. 功能需求

### 2.1 核心功能
- **摸头 (petpet)**: 生成摸头 GIF 动画
- **亲亲 (kiss)**: 生成亲亲表情包
- **揍 (punch)**: 生成揍人表情包
- **爬 (crawl)**: 生成爬表情包
- **拍 (pat)**: 生成拍头表情包
- **撕 (rip)**: 生成撕裂表情包
- **贴贴 (stick)**: 生成贴贴表情包
- **顶 (throw)**: 生成顶表情包

### 2.2 命令格式
```
#摸头 @用户
#摸头 123456789 (QQ号)
#摸头 自己
#表情包帮助
```

### 2.3 技术要求
1. **纯 Node.js 实现**: 使用 `sharp` 和 `gifencoder` 库处理图片和生成 GIF
2. **本地模板系统**: 参考 petpet-templates 设计，支持自定义模板扩展
3. **头像获取**: 通过 QQ API 获取用户头像
4. **性能优化**: 缓存常用素材，优化 GIF 生成速度

## 3. 技术方案

### 3.1 依赖库
- **sharp**: 高性能图片处理库
- **gifencoder**: GIF 编码器
- **canvas**: Node.js Canvas 实现（用于图像合成）
- **axios/node-fetch**: HTTP 请求获取头像

### 3.2 架构设计
```
apps/
  └── Petpet/
      └── Petpet.js          # 命令入口类

logic/
  └── petpet/
      ├── index.js           # 核心逻辑导出
      ├── generator.js       # GIF 生成器
      ├── templates.js       # 模板管理
      └── utils.js           # 工具函数

resources/
  └── petpet/
      ├── templates/         # 表情包模板
      │   ├── petpet/        # 摸头模板
      │   │   ├── 0.png ~ 4.png
      │   │   └── data.json
      │   ├── kiss/
      │   ├── punch/
      │   └── ...
      └── fonts/             # 可选字体
```

### 3.3 模板配置格式 (data.json)
```json
{
  "type": "GIF",
  "avatar": [{
    "type": "TO",
    "pos": [[0, 51, 94, 94], [12, 33, 90, 88], ...],
    "round": true
  }],
  "delay": 60
}
```

## 4. 开发阶段

### 阶段一: 基础设施 (优先)
1. 安装必要依赖 (sharp, gifencoder, canvas)
2. 创建目录结构
3. 实现头像获取功能

### 阶段二: 核心功能
1. 实现 GIF 生成器核心
2. 创建摸头 (petpet) 模板和逻辑
3. 添加命令处理类

### 阶段三: 扩展
1. 添加更多表情包模板
2. 实现模板热加载
3. 优化性能

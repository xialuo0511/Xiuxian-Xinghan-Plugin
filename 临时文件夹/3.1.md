## 核心升级

### 🌌 天象系统

每3-7天天象更替，影响所有对战：

| 天象 | 效果 |
|------|------|
| **五行失衡·金** | 金灵根攻击+50%，木灵根-30% |
| **五行失衡·木** | 木灵根恢复+50%，土灵根-30% |
| **五行失衡·水** | 水灵根暴击+30%，火灵根-30% |
| **五行失衡·火** | 火灵根攻击×2，防御-50% |
| **五行失衡·土** | 土灵根防御+80%，攻速-50% |
| **灵气潮汐** | 法术+60%，物理-40% |
| **天道镇压** | 境界压制失效 |
| **杀劫降临** | 伤害+100%，血量-30% |

### ⚡ 五行克制

```
金 → 木 → 土 → 水 → 火 → 金
```
克制方伤害+20%，被克方-20%

# 天地榜 2.0 升级策划案

> 升级目标：DAL架构迁移 + 天象系统 + 修仙特色玩法深化

---

## 一、现状分析

### 当前玩法

- 每日3次免费对战（可用摘榜令额外挑战）
- 匹配随机对手或NPC"灵修兽"
- 胜利/失败均获得积分和灵石
- 每周一0点结算，积分清零
- 积分可在天地堂兑换物品（仅周日可兑换）

### 存在问题

1. **技术债务**：使用MySQL，未迁移至DAL架构
2. **玩法单调**：每天只是重复对战，缺乏变化
3. **策略性不足**：无需思考，盲目对战即可
4. **修仙特色不足**：未与灵根、功法等核心系统联动

#### ⚡ **灵根克制加成**

在天地榜对战中引入五行相克：

```
金 → 克木 → 克土 → 克水 → 克火 → 克金
```

**克制效果**：对被克制灵根伤害+20%  
**被克效果**：受到克制灵根伤害+20%

> 与天象形成联动：天象"五行失衡·金"时，金灵根双重加成！

### 4.2 天象系统

```javascript
// 定时任务：每天检查天象是否需要更换
async function checkTianxiang() {
  const current = await redis.get('xiuxian:tiandibang:tianxiang');
  if (!current || Date.now() > current.end_time) {
    const newTianxiang = generateRandomTianxiang();
    await redis.set('xiuxian:tiandibang:tianxiang', newTianxiang);
    // 全服公告
    await notifyAllGroups(`【天象更替】${newTianxiang.name} 降临！`);
  }
}
```

### 4.3 五行克制

```javascript
function calculateLinggenBonus(attackerLinggen, defenderLinggen) {
  const keZhi = { '金': '木', '木': '土', '土': '水', '水': '火', '火': '金' };
  if (keZhi[attackerLinggen] === defenderLinggen) {
    return 1.2; // 克制加成20%
  }
  if (keZhi[defenderLinggen] === attackerLinggen) {
    return 0.8; // 被克减成20%
  }
  return 1.0;
}
```

# 技术栈 - 绝云间修仙 (xiuxian-emulator-plugin)

## 运行环境
* **Node.js**: 项目运行的基础环境，采用 ES Modules (`import`/`export`) 模块标准。

## 核心框架
* **Yunzai-Bot 插件架构**: 遵循其标准的插件开发规范，通过 `apps/` 响应指令。

## 数据库与存储
* **Redis**: 用于存储玩家实时数据（修为、纳戒、装备等）、任务队列（Scheduler）以及高频访问数据。
* **better-sqlite3**: 用于辅助性的持久化存储，利用 SQLite 的查询能力处理复杂数据关系。

## 关键库与依赖
* **pinyin-pro**: 处理中文字符的拼音转换，用于名称生成或搜索逻辑。
* **YAML**: 用于处理用户配置 (`config/`) 和默认配置 (`defSet/`) 的加载与合并。

## 系统架构
* **指令处理层 (`apps/`)**: 负责与玩家交互，解析群聊指令并调用逻辑层。
* **逻辑层 (`logic/`)**: 实现具体的修仙业务计算。
* **数据模型层 (`model/`)**: 封装数据访问逻辑和通用工具。
* **异步任务层 (`workers/`)**: 利用 Redis 的 List/ZSET 实现后台独立进程的任务调度（如定时结算、长期修炼任务）。
